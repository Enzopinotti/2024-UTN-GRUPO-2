# Antigal frontend

El frontend mantenido de Antigal usa **React 19 + Vite 8 + Vitest + Sass**.

La documentación completa del proyecto, requisitos, configuración, comandos, arquitectura y estado de modernización está en el [README raíz](../../README.md).

Comandos principales:

```bash
npm ci
npm run dev
npm run lint
npm test
npm run build
```

El servidor Vite usa el puerto **3000** y el build se genera en `build/`.
